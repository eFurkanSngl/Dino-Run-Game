2D GAME
Dinosaur Game, our dinosaur, which tries to overcome obstacles in the endless running type, tries to overcome various obstacles in various places.

Our goal in our game is to increase our score without hitting obstacles
the player can jump with the "SPACE" key to avoid obstacles and can lean over obstacles with the "down arrow" key.

Used Unity Version: 2022.3.27F1
Used Tools: Odin Inspector, DoTween.

Our game has 5 language options: German, Portuguese, English, Turkish, Spanish language options are available
